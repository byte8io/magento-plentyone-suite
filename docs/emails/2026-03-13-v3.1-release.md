# Mage2Plenty v3.1 - Customer Group Mapping & Critical Fixes

## What's New

- **Customer Group Mapping** - Order export now maps Magento customer groups to PlentyONE customer classes using your profile configuration (previously hardcoded to class 1)
- **Order Export Pagination Fix** - Resolved infinite loop when exporting large order batches caused by Magento SearchCriteria caching
- **Smarter Email Notifications** - Duplicate batch emails eliminated; alerts now include profile context for easier troubleshooting
- **Post-Processor Guard** - Product export post-processors no longer run when the parent process fails or is skipped
- **Company Rebrand** - All modules updated to Byte8 Ltd (formerly Soft Commerce)
