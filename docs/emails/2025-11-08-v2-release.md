# Mage2Plenty v2.0.0 - Major Release

## Breaking Changes

- **PHP 8.4 support added, PHP 8.0 dropped** - Minimum version now 8.1
- **15 modules consolidated** - Automatic upgrade, cleaner architecture
- **API namespaces relocated** - Custom integrations may need updates
- **MessageStorage deprecated** - Use MessageCollector instead

## Features

- **Email alerts for errors and warnings** - Configurable notifications
- **Auto-retry for failed order exports** - Handles PlentyONE downtime
- **One-click setup wizard** - Hours to minutes configuration time
- **Real-time notification dashboard** - All operations at a glance
- **Flexible product matching** - Use any attribute, not just SKU
- **Shipment import filtering** - Control by tracking ID presence
- **30% faster, 50% less memory** - Optimized performance

## Bug Fixes

- Order cancellation sync with PlentyONE
- Token refresh for expired sessions
- URL rewrite conflicts on import
- Race conditions in batch processing
