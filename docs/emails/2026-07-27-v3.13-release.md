# Mage2Plenty v3.13 - Order Identity, Sales Channels & Deferred Imports

## New

- **External order ID preserved** - the original PlentyONE reference (marketplace / manual entry) gets its own column and admin grid column; export no longer overwrites it on the Plenty side.
- **Deferred order import** - invoices/shipments blocked by payment review or on-hold are retried instead of silently lost (14-day window, then a one-time alert).
- **Real sales channel after export** - Magento orders are stamped with the exported PlentyONE referrer; order grid gains a channel tooltip.

## Fixed

- No more duplicate PlentyONE orders on export retries (external-id idempotency search).
- Manual-entry orders (channel 0) now export and render correctly - no longer dropped as "no channel".
- Stock drift detection skips Manage Stock = No SKUs (no more false alarms that can't self-heal).
- Item-mapping integrity check no longer fires false critical alerts when PlentyONE's externalId is unset.
- Order increment ID stays stable once linked (no more collect/import flip).

## Also in v3.12 (if upgrading from older)

- Product mapping on a schedule, on demand, or via CLI.
- Order import gating by PlentyONE status and creation date.

## Upgrade

Ships schema changes (two new order-mirror columns). Run `setup:upgrade`, `setup:di:compile` and `cache:flush`.
