# Mage2Plenty v3.2 - Stability, Performance & PHP 8.4 Compatibility

## Improvements

- **Queue Loop Circuit Breaker** - Prevents infinite relation link reprocessing
- **Notification Table Bloat Fix** - Batched cleanup, log level filtering, config toggle enforced
- **Auto-Create Attribute Values** - Missing values created before export to prevent batch rejection
- **Async Media Checksum** - Moved to message queue to prevent setup wizard timeouts
- **Queue Consumer Idle Polling** - All consumers sleep when idle, reducing DB overhead
- **PHP 8.4 Compatibility** - Implicit nullable type deprecations resolved across 9 modules

## Bug Fixes

- Fixed orders incorrectly canceled in PlentyONE after credit note import
- Fixed item import errors not persisting to item table when SKU was already set
- Fixed batch execution errors not surfacing in CLI and admin UI
- Fixed cascading "Product SKU is required" errors from post-processors
- Fixed creditmemo not created for canceled orders due to type mismatch
- Fixed variationId missing from PIM dedicated endpoint payloads
- Fixed memory leak in retry registry for long-running queue consumers
- Fixed request payloads bloating API error logs in production
