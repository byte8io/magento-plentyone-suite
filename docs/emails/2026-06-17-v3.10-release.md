# Mage2Plenty v3.10 - Self-Healing Stock-Drift Detection & Faster Incremental Sync

## What's New

- **Self-healing stock-drift detection** - Magento and PlentyONE physical stock are now compared automatically; transient gaps are auto-fixed hourly, and only genuinely stuck discrepancies are escalated in a weekly drift-report email.
- **No more export-queue deadlocks** - Fixes `plenty_stock_export_queue` deadlocks under concurrent load, and stops queueing rows when the stock-export schedule is off so the queue can't grow unattended.
- **Faster incremental sync** - The `collected_at` watermark is now indexed on every mirror table, so each scheduled "what changed since last run" lookup is index-backed instead of a full scan.
- **Maintenance hardening** - Batched, memory-safe cleanup for history, queue and orphaned stock, plus image import now works with `Magento_Downloadable` disabled.

## Post-Upgrade Notes

This release **ships schema changes** (a new `plenty_stock_drift_log` table and `collected_at` indexes), so run `setup:upgrade` - index creation may take a moment on large tables.

- **Drift detection and the weekly report are on by default**; adjust them under **Stock Settings** on the stock-export profile.
- **Orphan stock cleanup is off by default** (it's destructive) - enable it deliberately.
- **Export enqueue is now gated by the stock-export schedule** - explicit CLI/manual exports are unaffected.

Run `setup:di:compile` and `cache:flush` after upgrading.
