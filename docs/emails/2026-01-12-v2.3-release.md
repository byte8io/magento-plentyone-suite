# Mage2Plenty v2.3 - Tags & Export Improvements

## Features

- **Order Tag Management** - Assign and track PlentyONE tags on orders
- **Image Checksum Detection** - Smart detection of changed product images
- **Batch Export Architecture** - New infrastructure for reliable product exports
- **Locale-Aware Categories** - Proper category name resolution by language
- **Tag Creation UI** - Create PlentyONE tags directly from Magento admin

## Improvements

- **Centralized Tag System** - Unified tag handling across all domains
- **Enhanced Data Providers** - Faster item and variation data retrieval
- **Memory Optimization** - Reset cache during batch operations
- **Better API Response Handling** - Improved batch response mapping

## Bug Fixes

- Fixed category path resolution using correct locale
- Fixed property data deletion in flush operation
- Fixed email template configuration in preorder module
- Fixed type casting in category ID assignment
