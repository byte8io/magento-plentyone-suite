# Mage2Plenty v3.2.1 - Critical Patch: Inventory Reservation Error

## Critical Fix

- **Inventory Reservation JSON Truncation** — If you are seeing "SQLSTATE[22032]: Invalid JSON text in argument 1 to function json_extract" during order or stock synchronisation, this update is for you. Magento's inventory_reservation.metadata column (varchar 255) silently truncates JSON payloads exceeding 255 characters. Multiple modules, including Magento itself and our Plenty Stock module, write metadata to this column. When truncated, the resulting invalid JSON breaks all json_extract() queries on the table, blocking order export, order import and stock reservation processing. We strongly recommend updating immediately.

## What's New

- **Increased column size** — The inventory_reservation.metadata column is extended from varchar(255) to varchar(1024), preventing JSON truncation
- **Added safety guards** — All queries that read reservation metadata now include a JSON_VALID() check, so any future corrupt rows are gracefully skipped instead of causing a hard failure
- **Compacted metadata payloads** — Reservation metadata written by the Plenty Stock module now uses shorter keys and rounded values, reducing payload size
- **Post-upgrade note** — After updating, run setup:upgrade to apply the column change. If you have existing corrupt rows, run: DELETE FROM inventory_reservation WHERE NOT JSON_VALID(metadata) — they will be recreated on the next stock sync
