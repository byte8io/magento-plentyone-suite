# Mage2Plenty v3.14 - Self-Healing Stock Status, Safer Order Sync & Auth Resilience

## New

- **Stock status heals itself** - a new reconciler (CLI + hourly cron, on by default) detects in-stock products stranded as "out of stock" by Magento's MSI status cache and repairs them automatically; `plenty:stock:import --force` and the admin Refresh Stock button re-assert stock on demand.
- **Manual order exports act immediately** - the admin Export button and mass action bypass the settling-period defer; a new `--no-force` CLI flag runs exports with exact cron semantics for debugging.
- **Self-healing API authentication** - a revoked/rotated PlentyONE refresh token now triggers an automatic credential re-login instead of failing every sync until manual intervention.

## Fixed

- Booked PlentyONE orders are protected from address churn - scheduled re-exports never touch an exported order's addresses (forced exports still can, deliberately).
- One failing order no longer flags every clean order in the same import batch as "warning".
- Unsupported PlentyONE order types (reorders, offers, repairs) skip gracefully instead of erroring on every run.
- Shipment tracking numbers import exactly once - no more duplicate rows for multi-package orders; blank package numbers are ignored.
- Credit memos no longer fail when PlentyONE books a fee as shipping the Magento order doesn't carry (refund capped to refundable shipping).
- Unassigned-variation order lines (manual lines, deleted variations) now ship via SKU and reservation-source fallback instead of leaving orders stuck partially shipped.
- Stock drift no longer alarms on SKUs oversold in PlentyONE (negative stock floored at 0 for comparison).
- Manufacturers created in PlentyONE are collected reliably (own sync watermark).

## Upgrade

No schema changes. Run `setup:upgrade`, `setup:di:compile` and `cache:flush`. Note: a new hourly stock-status reconcile cron is enabled by default, and the admin "Out of Stock" toggle is re-asserted from PlentyONE on the next import for stock-managed products.
