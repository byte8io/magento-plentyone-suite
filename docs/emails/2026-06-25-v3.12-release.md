# Mage2Plenty v3.12 - Product Mapping & Order Import Controls

## New

- **Product mapping** - run on a schedule, on demand (Map / Unmap in admin), or via CLI.
- **Order import gating** - scope imports by PlentyONE status and creation date.

## Fixed

- Order properties now persist on import (were silently dropped).
- Bundle components in a non-default MSI source no longer rejected as out of stock.
- No more duplicate attribute options on re-import.
- Manufacturer name casing preserved on import.
- Batch product mapper now reports real counts (was a silent no-op).

## Also in v3.11 (if upgrading from older)

- Bidirectional bundle orders with per-component VAT preserved.
- Set-export on by default for new profiles.

## Upgrade

No schema changes. Run `setup:di:compile` and `cache:flush`.
