# Mage2Plenty v3.0 - New Product Export Engine

## Features

- **New Product Export Engine** - Command-based architecture with batch API calls
- **10x Fewer API Calls** - Smart batching exports up to 100 variations per request
- **Change Detection** - Skips unchanged data, only exports what's different
- **Dry-Run Mode** - Preview exports without changes via `--dry-run` flag
- **Credit Memo Partial Refunds** - Import credit memos with custom amounts
- **Configurable Order Retry** - Set max attempts and get email alerts on failure
- **Parent Product Auto-Resolution** - Child products auto-include their parent

## Improvements

- **Automatic Dependency Resolution** - Categories, properties and attributes pre-created
- **Immediate Data Persistence** - Properties and attributes saved right after export
- **Default API Timeouts** - Connection 60s, request 120s (was unlimited)
- **Centralized Email Alerts** - New ProfileNotification service for admin emails
- **Order Integrity Check** - Enhanced duplicate detection with unified service

## Bug Fixes

- Fixed zero-quantity null return in credit memo order items
- Fixed credit note order type prerequisite for creditmemo creation
- Fixed shipping profile query filter in variation data provider
- Fixed redundant property group exports when groups already exist
- Fixed batch message aggregation for PHP 8.4 compatibility
- Fixed system property setup command output and status tracking
